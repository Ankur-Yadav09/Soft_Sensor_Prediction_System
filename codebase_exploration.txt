● Here's a complete breakdown of the Soft Sensor Prediction System:

  ---
  Architecture Overview

  This is a modular Streamlit web app (26 Python modules, ~5,756 lines) for
  industrial soft sensor prediction. The primary model is a Denoising Autoencoder
  (DAE) built in PyTorch, with additional support for Random Forest, XGBoost,
  LightGBM, and LSTM. The codebase is split into a pure-Python business-logic
  layer (src/) and a thin Streamlit UI layer (src/ui/).

  ---
  Neural Network: IndustrialDAE

  A multi-task Denoising Autoencoder with 3 components:

  Corrupted X (masked) ──→ Encoder ──→ Latent State (bottleneck)
                                            │
                                ┌───────────┴───────────┐
                                ↓                       ↓
                             Decoder                Predictor
                         (Reconstruct X)          (Predict Y/KPIs)
                         MSE Loss                 Huber Loss

  - Encoder: input → 128 → 64 → latent_dim (BatchNorm + ReLU + Dropout)
  - Decoder: Reconstructs all input sensor features (denoising)
  - Predictor: Directly predicts KPI targets from latent state
  - Combined loss: recon_loss + weight_to_pred × pred_loss

  The key idea: by learning to reconstruct corrupted/masked sensor data, the
  model learns a robust latent representation that generalizes better to KPI
  prediction.

  ---
  Model Wrappers (src/models/wrappers.py)

  All models — regardless of framework — expose the same interface:

      wrapper.predict_scaled(X_scaled) → np.ndarray

  Three wrapper classes:
  - DAEWrapper     — PyTorch IndustrialDAE
  - LSTMWrapper    — PyTorch LSTMPredictor (tiled-window sequences)
  - SklearnWrapper — Random Forest, XGBoost, LightGBM (MultiOutputRegressor)

  Pages and evaluation code always call wrappers, never raw model internals.

  ---
  12-Method Auto Feature Selection (src/feature_selection/auto_selector.py)

  The consensus engine runs 12 independent selection methods and aggregates
  their votes into a single confidence score per feature:

    Confidence = 60% × selection_frequency + 40% × avg_normalized_score

  Methods by category:
  ┌────────────────────────┬──────────────────────────────────────────────┐
  │       Category         │                   Methods                   │
  ├────────────────────────┼──────────────────────────────────────────────┤
  │ Supervised Stats (3)   │ Target Correlation, F-Test, Mutual Info      │
  ├────────────────────────┼──────────────────────────────────────────────┤
  │ Tree Importance (3)    │ Random Forest, XGBoost, LightGBM             │
  ├────────────────────────┼──────────────────────────────────────────────┤
  │ Regularization (2)     │ Lasso, Elastic Net (multi-task variants)     │
  ├────────────────────────┼──────────────────────────────────────────────┤
  │ Wrapper Methods (3)    │ RFE, Sequential Forward, Sequential Backward │
  ├────────────────────────┼──────────────────────────────────────────────┤
  │ Dim. Reduction (1)     │ PCA Loadings Analysis                        │
  └────────────────────────┴──────────────────────────────────────────────┘

  Output categories:
  - Highly Recommended (≥70% confidence)
  - Recommended        (≥45%)
  - Optional           (≥20%)
  - Remove             (<20%)

  Also produces: correlation heatmaps, VIF analysis, per-feature reasoning
  (correlation value, p-value, VIF, regularization impact).

  ---
  Full Data Pipeline

  Excel / CSV Upload
      ↓
  SQLite (Parquet blobs — dataset versioning, instant switching)
      ↓
  Preprocessing
    → Type coercion
    → Imputation (mean / median / ffill / bfill / zero)
    → Outlier treatment (IQR capping / Winsorization / Z-score removal)
    → Domain filters (per-tag min/max clipping)
    → Train/Test Split (80/20) + StandardScaler
      ↓
  Auto Feature Selection (12-method consensus)
      ↓
  Training
    → DAE: masked inputs → dual loss (MSE + Huber) → Adam optimizer
    → sklearn: MultiOutputRegressor (RF / XGB / LGB)
    → LSTM: tiled-window sequences
      ↓
  Auto-save: model.pth|pkl + scaler_x.pkl + scaler_y.pkl +
             columns.pkl + metadata.pkl
      ↓
  Evaluation (test set: RMSE, MAE, R², MAPE per target)
      ↓
  What-If Analysis (feature sweep → KPI sensitivity trends)

  ---
  Key ML Concepts

  1. Denoising Autoencoder: Random feature masking during training forces the
     model to learn robust inter-sensor correlations
  2. Multi-task learning: Joint reconstruction + KPI prediction from the same
     latent space
  3. Masking ratio: Fraction of input features zeroed out per sample during
     training (default 10%)
  4. Huber loss for prediction: Robust to outliers in industrial KPI data
  5. Auto-train mode: Stops automatically when R² > 0.85 threshold is met
  6. Consensus feature selection: 12 independent methods vote on each feature;
     confidence score = 60% frequency + 40% normalized score
  7. Wrapper abstraction: All model types share predict_scaled() so pages are
     model-agnostic
